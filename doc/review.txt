SUGGESTED PRIORITY ORDER
------------------------
  1. Webserver: command injection, path traversal, uncaught exceptions (network-facing surface).
  2. floatLog mutex bugs, out::_setout unlock bug, records_in_file uninitialized - these corrupt
     or crash the core during normal operation.
  3. Interface thread lifecycle (run_flg race, mb re-setting it, unchecked pthread_create/join)
     - shutdown hangs.
  4. float16/filters arithmetic bugs - silent data corruption.
  5. Dead-code cleanup and leftover tcFarmControl names / debug defines.
